> **말로도, 손으로도 주문하는 접근성 기반 온디바이스 음성 AI 카페 키오스크**  
> 한성대학교 컴퓨터공학부 · 2026학년도 2학기 「모바일시스템응용프로젝트 (V021009)」 산학협력프로젝트 (8분반 1팀)

## 1. 프로젝트 소개

**온키오스크(OnKiosk)**는 복잡한 다단계 터치 UI, 작은 글씨, 화면 높이 제약으로 키오스크 주문에 어려움을 겪는 **고령층(73세 페르소나), 저시력자, 휠체어·저신장 이용자**를 위한 온디바이스 AI 기반 배리어프리 카페 안내 키오스크입니다.

본 저장소는 키오스크 화면·터치·음성 상호작용을 담당하는 **Next.js 15 / React 19 프론트엔드 웹 애플리케이션**입니다. **Orange Pi 5 Plus (RK3588 16GB)** 백엔드 5종 REST API(`/api/stt`, `/api/action`, `/api/tts`, `/api/orders`, `/api/stamps`)와 연동하여 완전 오프라인(외부 클라우드 API 호출 `0건`) 환경에서 전체 왕복 **약 `2.6초`**로 동작하며, 네트워크 지연·오류 시에는 프론트엔드 내부 로컬 규칙 파서(`resolveIntent`)로 즉시 폴백해 주문 흐름이 끊기지 않도록 설계되었습니다.

### 핵심 특징 및 검증 성과

- **배리어프리 4대 이용 모드 & 동일 상태(Zustand) 공유**
  - **기본 모드 (터치 + 음성)** / **하단 모드 (휠체어·저신장: 주요 조작부 하단 배치)** / **고대비 모드 (큰 글씨 · 흑/황 고대비 · 2열 대형 카드)** / **음성 모드 (자동 연속 듣기)**
  - 터치 조작과 음성 발화가 동일한 Zustand 스토어를 공유하며, **TTS 음성 안내 재생 중 마이크 자동 일시정지**로 하울링과 오인식을 방지합니다.
- **6단계 직관 주문 흐름 & 3중 Fail-Safe**
  - 시작 화면 없이 즉시 메뉴 선택으로 진입(`메뉴 → 옵션 → 장바구니 → 적립 → 결제 → 완료`)
  - ① **1중 서버 정책 가드레일**(품절 안내 · 필수 옵션 되묻기) → ② **2중 프론트 로컬 규칙 폴백**(`/api/action` 4초·주문 저장 6초 초과 또는 오류 시 `resolveIntent` 즉시 처리) → ③ **3중 직원 호출**(`call_staff`) 3단계 안전망을 갖췄습니다.
- **온디바이스 백엔드 연동 & AI 정량 성과**
  - `Orange Pi 5 Plus (RK3588 NPU · W8A8 1.78GB)` + `sherpa-onnx SenseVoice` + `983문구 WAV 캐시 / VITS` 연동으로 Wi-Fi 차단 환경에서 **외부 API 호출 `0건`**, E2E 응답 **약 `2.6초`** 실증
  - `v7` 데이터셋 `7,600건`(19종 Action 균등·중복 0건) 기반 GPU LoRA BF16(`1,520건` 평가): **JSON 성공률 `99.9%`**, **Action 정확도 `91.6%`**, **`no_action` 방어 `80.0%`** _(RKLLM W8A8 양자화 모델 대상 1,520건 전체 재평가는 향후 과제)_
- **CI 5단계 & 자동화 테스트**: GitHub Actions CI(포맷·린트·타입체크·테스트·빌드) 및 코드 기준 총 **`370건`** 자동화 테스트 통과(프론트엔드 `node --test 45건` + 백엔드 `pytest 325건`)

## 5. 기술 스택 및 프로젝트 구조

| 구분             | 기술                                                        |
| :--------------- | :---------------------------------------------------------- |
| **Framework**    | Next.js 15 (App Router) + React 19 + TypeScript strict      |
| **State & Form** | Zustand (`src/store/kiosk-store.ts`), react-hook-form + zod |
| **Style**        | Tailwind CSS v4 (CSS 변수 기반 일반/고대비 테마 전환)       |
| **Backend Sync** | FastAPI REST 연동 + 로컬 규칙 폴백 (`resolveIntent`)        |

```text
frontend/
├── .github/workflows/ci.yml # PR 5단계 자동 검증 (포맷·린트·타입·테스트·빌드)
├── docs/                    # 개발문서 6종 (.hwp)
├── src/
│   ├── app/                 # Next.js App Router 진입점 및 전역 스타일
│   ├── components/          # 키오스크 프레임, 배리어프리 모드 바, 단계별 화면 컴포넌트
│   ├── data/                # 단일 출처 메뉴·카테고리·옵션·안내 데이터
│   ├── hooks/               # 음성 STT·TTS 연동 및 화면 스케일 훅
│   ├── lib/                 # API 클라이언트, 규칙 폴백(intent), 테마, 금액 계산, Zod 스키마
│   └── store/               # Zustand 통합 상태 및 Action 핸들러
└── tests/                   # 음성 주문 흐름·세션 자동화 테스트 (node --test)
```

## 6. 실행 및 검증

```bash
npm install
npm run dev           # 개발 서버 실행 (http://localhost:3000)
npm run format:check  # Prettier 포맷 검사
npm run lint          # ESLint 검사
npm run typecheck     # TypeScript 타입 체크
npm test              # 음성 주문 상태 전이·세션 테스트 (node --test)
npm run build         # 프로덕션 빌드
```
